# Pharma Language Style Guide

本规范用于 Pharma Slides 的肿瘤医学汇报、证据锚定型 PPT、监管沟通材料、指南摘要和管理层临床开发汇报。语言风格参考 ASCO/WCLC/ESMO、FDA、NMPA/CDE、NCCN/CSCO 的公开材料，提炼共同规律：以证据为中心，客观、精确、平衡，并保留监管视角。

## Core Principles

默认语气是“先摆证据，再给边界明确的解释”。标题或核心结论应尽量交代：研究来源、人群、方案或对照、终点、结果方向、数据成熟度和主要限制。

优先使用：`显示`、`提示`、`支持`、`达到预设终点`、`未达到预设终点`、`方向上支持`、`与既往安全性特征一致`、`尚未成熟`、`需进一步随访`、`需前瞻性验证`。

避免使用：`证明有效`、`显著优于`、`疗效惊艳`、`明显领先`、`重磅结果`、`最佳数据`、`全线优胜`、`颠覆格局`、`一锤定音`、`黄金方案`、`实战心法`。这些词没有说明终点、统计量、人群、随访时间和不确定性，容易把研究结果说成确定性结论。

标题结构：

- `[Study]: [regimen] met primary [endpoint] in [population]`
- `[Study]: [endpoint] favored [regimen]; OS/subgroup data remain immature`
- `[Guideline]: [recommendation level] for [population]`
- `[Regulatory]: key review issue is [benefit-risk / endpoint adequacy / safety monitoring]`

## Efficacy Reporting

疗效表达必须说明终点和证据等级。3 期随机研究优先写研究名、人群、主要终点、HR 或效应量、95% CI、p 值、随访时间或数据截止日期。单臂研究、早期研究和 post hoc 分析不能写成直接比较结论。

推荐句式：

- `[Study] 在 [population] 中达到预设主要终点 [endpoint]，结果为 [effect size]。`
- `[endpoint] 结果支持 [regimen] 相比 [comparator] 的疗效获益；OS 数据在当前数据截止时尚未成熟。`
- `[endpoint] 在方向上支持 [regimen]，但该分析为描述性/探索性分析。`
- `疗效幅度应结合研究设计、对照方案、随访时间、后续治疗和适应症背景解释。`

## Safety Reporting

安全性表达要具体，不要用一句“安全性良好”替代数据。应分开呈现 grade >=3 AE、TRAE、SAE、导致停药的不良事件、死亡事件、免疫相关不良事件、AESI 和需监测的临床风险。

推荐句式：

- `安全性特征与该药物/同类药物既往报道基本一致。`
- `当前随访未观察到新的安全性信号。`
- `grade >=3 TRAE、SAE、停药和死亡事件应按治疗组分别呈现。`
- `安全性解释需结合治疗场景：围手术期/辅助治疗场景对毒性容忍度通常低于晚期后线治疗。`

避免：`安全性良好`、`毒性可控`、`几乎没有安全性问题`、`不良反应轻微`。如需表达可管理性，必须同时给出事件类型、严重程度、处理方式和停药比例。

## Benefit-Risk Assessment

获益风险表达要把疗效幅度、疾病背景、未满足需求、毒性负担、风险缓解措施和数据不确定性放在同一框架下。

推荐句式：

- `在 [setting] 中，观察到的 [endpoint] 获益可能具有临床意义，尤其考虑到 [unmet need / curative intent / limited alternatives]。`
- `主要不确定性包括 OS 成熟度、获益持续性、亚组一致性、安全性随访和后续治疗影响。`
- `风险缓解需关注 AE 监测、剂量调整、患者选择和治疗时序。`

避免：`获益远大于风险`、`风险可忽略`、`上市确定性高`、`价值主张清晰`。

## Subgroup Analysis

亚组结果必须交代是否预设、是否有统计效能、样本量、置信区间宽度和交互检验。除非研究设计支持，不应把亚组趋势写成确定结论。

推荐句式：

- `预设亚组中治疗效应总体一致。`
- `该亚组分析为探索性分析，研究未针对该亚组结论进行充分把握度设计。`
- `点估计方向上支持 [regimen]，但置信区间较宽，解释应谨慎。`
- `未进行预设交互检验时，不应得出正式亚组差异结论。`

避免：`所有亚组全面胜出`、`PD-L1 阴性也明确获益`、`特定亚组证明优势`。

## Exploratory Findings

探索性发现包括 biomarker、ctDNA、替代终点、pCR/MPR 与长期结局关联、事后分析和真实世界补充分析。默认表达为 hypothesis-generating，除非已有前瞻性验证。

推荐句式：

- `该探索性分析提示 [marker] 与 [endpoint] 可能相关，需前瞻性验证。`
- `该结果支持进一步研究，不应作为实践改变的单独依据。`
- `探索性 biomarker 发现应与主要疗效和安全性结果分层呈现。`

避免：`发现核心预测因子`、`直接指导临床选择`、`锁定最佳人群`。

## Limitations

限制不应只放在脚注里。凡影响主结论解释的限制，都应在正文或 callout 中说明。

常用句式：

- `OS 随访仍不成熟，需更长随访确认长期获益。`
- `跨试验比较为描述性比较，不能替代头对头证据。`
- `研究未针对亚组结论进行统计效能设计。`
- `单臂数据需结合历史对照、疾病自然史和监管要求解释。`
- `Final values should be verified against the latest publication or conference presentation before use.`

## Competitive Positioning

竞争格局表达应是 evidence map，不是产品排序。比较不同研究时，应先列出设计、人群、对照、终点层级、随访时间、biomarker 定义、后续治疗和安全性收集差异。

推荐句式：

- `现有 3 期研究在人群、对照和终点层级上存在重要差异，不宜直接得出疗效排序。`
- `[Study A] 与 [Study B] 不是头对头研究，比较仅用于描述证据格局。`
- `相对定位需综合标签范围、指南推荐、疗效成熟度、安全性负担和实施可行性。`

避免：`明显领先`、`同类最佳`、`最强方案`、`全面碾压`。

## Executive Communication

管理层汇报可以更短，但不能降低证据标准。结论应转化为决策含义，并保留关键不确定性。

推荐结构：

- `Evidence: [study/dataset] supports [clinical or regulatory implication] in [population].`
- `Decision relevance: [filing / trial design / evidence generation / positioning].`
- `Key uncertainty: [OS maturity / safety / subgroup / comparator / operational feasibility].`
- `Next step: [source verification / regulatory interaction / backup slide / additional analysis].`

避免：`上市无忧`、`确定性很高`、`弹药充足`、`价值主张清晰`。

## Regulatory Communication

### FDA Style

FDA 风格强调 benefit-risk、substantial evidence、key review issue、uncertainty、适应症人群和数据充分性。

推荐句式：

- `关键审评问题是 [endpoint/result] 是否足以支持 [population] 中的临床获益。`
- `观察到的获益需与 [toxicity / uncertainty / available therapy] 权衡。`
- `应评估随访充分性、缺失数据、敏感性分析和安全性数据库规模。`
- `拟定适应症应与入组人群、终点结果和总体证据一致。`

避免：`FDA 会认可`、`审评风险低`、`可直接支持获批`、`监管无障碍`。

### NMPA / CDE Style

CDE 风格强调“审评考虑”和“支持注册”的证据条件。常用表达包括：`支持注册`、`关键研究`、`主要研究终点`、`临床获益`、`获益风险`、`充分评估`、`随访时间`、`敏感性分析`、`独立影像评估`。

推荐句式：

- `应结合目标适应症、药物作用机制、研究设计和终点特征评价临床获益。`
- `单臂关键研究应明确主要终点定义、统计假设、历史对照依据、有效性分析集和敏感性分析。`
- `安全性评价应考虑样本量、暴露时间、SAE、AESI 和长期风险。`
- `递交前应核实最低随访时间及支持上市申报所需数据完整性。`

避免：`达到 CDE 要求`、`注册路径清晰`、`单臂数据足够上市`，除非有明确法规、指导原则或沟通纪要支持。

## Guideline-Based Communication

指南表达应说明人群、治疗线数、biomarker 状态、推荐级别和证据等级。NCCN 风格常区分 `preferred`、`other recommended`、`useful in certain circumstances` 和证据类别；CSCO 风格通常同时考虑证据等级、推荐等级、药物可及性、地区差异和专家共识。

推荐句式：

- `[Regimen] is listed as [preferred/recommended/useful in certain circumstances] for [population].`
- `CSCO 推荐应同时呈现证据级别和推荐等级。`
- `指南纳入不等同于头对头优效证据。`
- `指南语言应避免扩展到未覆盖的人群或治疗线数。`

避免：`指南强推`、`标准答案`、`所有患者均适用`、`指南确认最佳方案`。

## Evidence-Anchor Language

使用原文 PDF、会议 poster、ODAC 幻灯或指南表格截图时，必须标注证据角色，避免把示意图伪装成真实结果。

推荐写法：

- `Source: [study/publication/congress], [data cutoff if available].`
- `Original evidence crop; do not restyle values.`
- `Schematic; not a trial result.`
- `Cross-trial comparison; descriptive only.`
- `Unsupported claims should remain evidence-pending.`

AI 生成 PPT 大纲时，每个证据页应包含 `source_id`、`asset_type`、`crop guidance`、`claim supported`。没有来源支撑的结论不得进入主标题。

## Naturalness Pass

自然度终检只在医学准确性、证据边界和规范术语已经确认后执行。优先级始终是：证据准确性 > 监管与指南术语 > 统计精确性 > 表达自然度。自然度优化不得改变研究结论、数字、终点、分析集、因果强度、数据成熟度或不确定性。

### 推荐处理

- 删除不承载事实的铺垫和泛化意义，如“值得注意的是”“具有重要意义”“为未来奠定基础”。直接进入研究、结果或决策问题。
- 将“专家认为”“研究显示”“多项资料表明”等模糊归因替换为具体研究、指南、监管文件或数据集；无法确认来源时标记为 `evidence-pending`。
- 保持核心术语稳定。不要为避免重复而轮换 `OS`、`总生存期`、`生存获益` 等并不完全等价的表达。
- 在不改变逻辑关系的前提下调整句长，避免连续句式完全一致；短句用于结论，较长句用于交代条件、限制和解释边界。
- 避免机械的三段式列举、否定式排比、口号式金句和模板化积极结尾。项目数量由证据决定，不为追求形式刻意改成两项或四项。
- 减少不必要的破折号、粗体、表情符号、聊天式开场白和“希望这对您有帮助”等助手残留。
- 用具体的决策含义、不确定性或下一步证据需求收尾，不用“前景广阔”“未来可期”等空泛结论。
- 保留必要限定语，如“可能”“探索性”“描述性”“尚未成熟”“需进一步验证”。可删除重复限定，但不得降低不确定性等级。

### 不采用的通用人性化规则

- 不以第一人称、幽默、情绪反应或“个人观点”替代医学判断。
- 不故意制造结构混乱、跑题或不完整句子来显得更像人工写作。
- 不机械删除连接词、三项列举或重复术语；医学逻辑、固定术语和可读性优先。
- 不以“去 AI 痕迹”评分替代事实核验、统计审核、医学审核或合规审核。

### 交付前检查

- 事实、数字、研究名称、终点、分析人群、数据截止日期和引用是否保持不变？
- 探索性、描述性、post hoc、单臂和跨试验比较的限定是否仍然清楚？
- 每个归因是否可追溯到具体来源，或已明确标记证据缺口？
- 是否删除了无信息量的铺垫、宣传词、口号式结尾和聊天助手残留？
- 是否为了“换词”而改变了医学术语、监管措辞或结论强度？
- 句子是否自然、直接、专业，同时保留必要的复杂性和不确定性？
